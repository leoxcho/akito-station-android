# Android 1.0.1

Adds consent-gated Search Cover Art to game editing, editable title queries, system-aware Libretro catalog matching, an adaptive native results grid, explicit selection/application and immediate library refresh. All runtime-adapter systems and other recognized systems are searchable where catalog coverage exists. Settings can disable online artwork. Local image import remains available.

Version code 2, package app.akitostation.android. Database remains schema 1; no migrations, runtime-routing changes or storage-grant changes. Uses the existing permanent production key; a signed APK and verified upgrade are required before publication.
