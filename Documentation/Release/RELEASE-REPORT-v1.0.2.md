# Android v1.0.2 release verification

VersionName 1.0.2, versionCode 3, package app.akitostation.android. Source implementation completed in the requested Android folder. The macOS source and release were not modified or uploaded.

DuckStation was absent from both the built-in catalog and manifest queries. The new PS1 adapter declares its verified publisher package, checks the actual installed app and enabled/exported activity, and sends bootPath/content URI plus data/ClipData read permission to EmulationActivity. The publisher's official README identifies com.github.stenzek.duckstation; its last Android source at 81da9be2d1040665ebfaf2db6d7fdb710a48a383 confirms EmulationActivity, bootPath, resumeState and ContentResolver file handling. The official old APK URL returned 404. Current installed DuckStation binaries/gameplay were not independently exercised; the owner is testing physical hardware separately.

Recognized PS1 formats: CUE, CHD, M3U, BIN, IMG, ISO, PBP, ECM, MDS, MDF, CCD and EXE. Shared formats need a PS1/PSX/PlayStation folder or metadata override. BIN/IMG/EXE scan only within PS1 folders; BIOS/key names are excluded. Sibling files and playlists can require DuckStation's own folder grant. Recognition is not a gameplay/container compatibility claim.

All 12 existing adapters audited: PPSSPP, PPSSPP Gold, Dolphin (GameCube/Wii), melonDS, upstream Mupen64Plus-AE alpha, NES.emu, Snes9x EX+, GBC.emu (GB/GBC), GBA.emu, MD.emu, PCE.emu and Saturn.emu. Publisher contracts confirmed the existing package/activity/action mappings; none were demonstrably stale. PCE's com.PceEmu Android override remains correct. Detection now requires enabled/exported configured activity as well as installed/enabled app. A package alias or unsupported fork is not inferred as compatible. See RUNTIME_SUPPORT.md for contracts and sources.
