# Akito Station Android 1.0.0 — production release

Native Kotlin/Compose library frontend with document-provider import, adjacent/imported artwork, editable title/system, favorites, search/filter/sort, recent accepted launches, grid settings, controller focus navigation and persistent settings.

Adds source-verified external adapters for Dolphin, melonDS, Mupen64Plus-AE alpha and seven EX-family applications alongside PPSSPP/Gold. Games and runtime-owned saves stay outside Akito; no game/BIOS/key/emulator payload is bundled. No gameplay is claimed verified.

Default update channel: leoxcho/akito-station-android, Android tags/APKs only. Owner signing instructions and complete device acceptance matrix accompany the candidate. The public APK is signed with the permanent production certificate. Physical-device acceptance is owner-confirmed; individual runtime gameplay results are not inferred from that confirmation.
