# Known limitations

Physical hardware gameplay and physical controllers are being tested separately by the owner. Automated controller evidence is simulated key dispatch/focus navigation. Current installed DuckStation binaries were not independently exercised; the package and launch contract are grounded in the publisher's official README and last published Android source. Its old official APK URL returned 404.

Android package visibility may hide unsupported apps. Known adapters are mapped to verified publisher interfaces; unknown launchable document handlers still require the user's confirmation of console support. Android has no emulator-console capability registry. Upstream Mupen64Plus-AE alpha support does not imply FZ/fork support.

Shared disc formats require a recognized system folder or metadata override. BIOS/key files are excluded. Multi-file discs/playlists need emulator-owned folder access; one document read grant does not grant sibling files. Format recognition is not gameplay compatibility. Emulators manage BIOS setup, saves and gameplay controls independently.

No bundled emulators, games, BIOS, firmware or keys; no embedded emulation, Play billing/Android PRO entitlement, cloud sync or emulator save management. Uninstalling Akito removes private metadata/covers; original games and external saves remain with their owners. Updates open release review and do not automatically install APKs.
